# YOLO Dataset Annotations

This directory holds the future human annotations for the proprietary Legal Metrology packaging dataset.

## Structure
- `images/`: The source images to be annotated (linked or copied from `dataset/raw`).
- `labels/`: The YOLO normalized `.txt` label files generated by human annotators.
- `classes.json`: The single source of truth for the classes mapping.

## Annotators Notice
Please read the root `docs/yolo-annotation-guide.md` before adding files here.
**Do not invent bounding boxes**. If a label is not visibly identifiable, do not draw it. The pipeline strictly handles the absence of labels as valid ground truth.

## Required Format
Each label file in `labels/` must have exactly the same basename as the image file (e.g., `back.jpeg` -> `back.txt`).
Each line in the `.txt` file represents one bounding box in standard YOLO format:
`class_id x_center y_center width height`

All coordinates must be normalized between `0.0` and `1.0`.
