# Human Verification Plan for Weak Candidates

This document outlines a lightweight, local-first workflow for converting `weak_candidate` pseudo-labels into `human_verified` ground truth for the SIH dataset.

## The Goal
To avoid clicking and dragging boxes from scratch, a human annotator will merely *review* and *nudge* the boxes generated by the OCR weak supervision script.

## The Workflow

### 1. Preparation
1. Ensure the `experimentWeakSupervision.js` script has run, which populates `dataset/reports/yolo/weak-candidates/` with `.txt` files.
2. Install [LabelImg](https://github.com/HumanSignal/labelImg) locally: `pip install labelImg`

### 2. Annotation Review
1. Open LabelImg.
2. Open Dir: Select `dataset/annotations/yolo/images/`
3. Change Save Dir: Select `dataset/annotations/yolo/labels/` (This ensures we don't overwrite the original weak candidates, we create the ground truth in the official folder).
4. **CRITICAL STEP**: Copy the `.txt` files from `dataset/reports/yolo/weak-candidates/` into `dataset/annotations/yolo/labels/` BEFORE starting LabelImg, so the tool loads the pre-generated boxes!
5. Select YOLO format in the left toolbar.
6. For each image:
   - If the `declaration_panel` box looks correct, do nothing.
   - If the box is slightly off, drag the edges to fix it.
   - If the box is completely wrong or missing, delete it or draw a new one.
   - Click Save. Move to next image.

### 3. Systematic Promotion
A backend utility (`annotationVerificationService.js`) will detect which files in `labels/` differ from the original `weak-candidates/`.
- If a file exists in `labels/`, its provenance is updated from `weak_candidate` to `human_verified`.
- The service will track `reviewStatus` (approved vs corrected).

## Cloud UI Alternative (Not Recommended Currently)
While tools like CVAT or Roboflow are excellent, they require uploading the proprietary dataset to a cloud server. Given the SIH data privacy requirements and the extremely small current dataset (20 images), keeping this purely local using LabelImg is the safest and most efficient path.
